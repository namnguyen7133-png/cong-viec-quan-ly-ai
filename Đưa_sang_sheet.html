Hệ Thống Quản Lý Sản Phẩm Affiliate

Phân loại công việc tự động hóa và thủ công cho chiến dịch Shopee Affiliate

Tổng quan quy trình

Trang web này giúp phân loại các công việc trong quy trình xử lý sản phẩm từ Shopee Affiliate. Một số công việc có thể tự động hóa bằng Google Apps Script và AI (Gemini, ChatGPT, Grok, DeepSeek), số khác cần xử lý thủ công.

1. Phân loại sản phẩm theo tầng giá

  • 1
    Lấy link sản phẩm từ file CSV Shopee Affiliate Tự động bằng Apps Script
  • 2
    Đưa vào Google Sheet "KHO_CHO_DU_YET" Tự động bằng Apps Script
  • 3
    Phân loại theo tầng giá:
    Tầng L: < 200K Tầng T: 200K-1TR Tầng C: 1TR-5TR Tầng D: > 5TR
    Tự động bằng Apps Script
  • 4
    Chọn theo tên sản phẩm (cột E) và giới tính (cột D) Tự động bằng Apps Script
  • 5
    Đưa lên lưu kho, bày hàng, kể chuyện ngụ ngôn Tự động bằng AI

2. Lên lịch đăng bài theo giới tính, tuổi teen

  • 1
    Lấy link sản phẩm từ CSV hàng ngày Tự động bằng Apps Script
  • 2
    Đưa vào Google Sheet Tự động bằng Apps Script
  • 3
    Tạo lịch đăng bài theo ngày, giới tính, tuổi teen Tự động bằng AI (Gemini/ChatGPT)
  • 4
    Đưa lên bày hàng, lưu kho Thủ công: Copy-paste, soạn tài liệu

3. Chiến dịch sản phẩm với công thức tài chính

  • 1
    Lấy link sản phẩm từ CSV Tự động bằng Apps Script
  • 2
    Áp dụng công thức thuật toán đầu tư, tài chính Tự động bằng AI (Grok/DeepSeek)
  • 3
    Tạo lịch đăng bài theo quy tắc ngày đặc biệt Tự động bằng AI (Gemini/ChatGPT)
  • 4
    Copy sang Google Sheet để tạo lịch đăng bài Thủ công: Copy-paste

Phân Tích CSV & Xuất Google Sheet

Tải lên file CSV từ Shopee Affiliate để phân tích và tạo cấu trúc Google Sheet tự động.

Kéo thả file CSV vào đây hoặc click để chọn file

Kết quả phân tích:

Hệ thống quản lý sản phẩm Affiliate © 2023 - Tự động hóa với Google Apps Script và AI

Quy trình tối ưu: Tự động hóa xử lý dữ liệu + AI tạo nội dung + Thủ công điều chỉnh cuối

async function sendToGoogleSheet(userData) { // THAY URL NÀY BẰNG URL BẠN VỪA COPY Ở BƯỚC 1 const GOOGLE_SCRIPT_URL = "URL_WEB_APP_CỦA_BẠN"; const payload = { userName: userData.name, // Tên người dùng productName: userData.spName, // Sản phẩm khớp content: userData.aiPost, // Bài viết AI link: userData.shopeeLink, // Link sản phẩm scheduleTime: userData.time // Giờ bạn muốn đăng }; try { const response = await fetch(GOOGLE_SCRIPT_URL, { method: "POST", body: JSON.stringify(payload) }); const result = await response.text(); alert("Kết quả: " + result); } catch (error) { console.error("Lỗi khi gửi sang Sheet:", error); alert("Không gửi được dữ liệu sang Sheet!"); } }
